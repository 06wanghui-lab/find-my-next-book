# 📚 NovelScout · 搜书小助手

**找下一本真正想看的书。**

A personal project for discovering Chinese web novels based on reading preferences, with recommendations backed by verifiable sources.

## 🤔 为什么做这个？

作为一个有着近二十年网文阅读史的资深杂食党，通勤路上、吃饭的时候、睡觉之前，能品鉴一篇美味的小说，一直是我生活中很重要的快乐来源。

之前都是随机找一些推文博主搜相关tag，但经常看了好几章才发现完全不是自己想看的东西。

而且很多时候，我想找的根本不是某个固定 tag。

比如喜欢一本无限流，可能是因为副本设计精彩、世界观宏达、群像写得好；喜欢一本古言，可能是因为女主的成长线，而不是单纯想看重生或者宅斗。

另外还有一些官方标签不太方便写、或者根本没有明确分类的内容，比如某些 18+ 情节和比较细的感情线偏好。这些信息有时反而能从读者书评、书单和讨论中找到线索。当然，读者评价也不一定准确，还是需要尽量交叉核对。

之前有次看完一本重生文，我跑去问 AI 有没有类似的小说推荐。结果它一本正经地给我推荐了一本根本不存在的书，还给它安了个从没写过这本书的作者。🥲

最近突然又找不到之前和朋友存的书单，就想着干脆自己做一个小工具。

希望它以后能做到：

- 📖 **按口味找书** — 不只是匹配标签，还能告诉它喜欢某本书的哪些地方。
- 🔎 **跨平台找文** — 不用每个平台来回翻，说不定还能挖到一些平时注意不到的好文。
- ✅ **别乱编书名** — 尽量核对书名、作者和原站链接。查不到就说查不到，不要硬编。
- 💗 **记住我的口味** — 读过什么、喜欢什么、踩过什么雷，下次推荐的时候最好都能记得。



## 🛠️ 目前进度

项目还在开发中，目前已经实现：

- 根据自然语言提取阅读偏好
- 搜索并整理候选小说
- 尝试核对书名、作者及原站信息
- 根据阅读偏好排序并解释推荐理由
- 在本地记录阅读偏好和反馈
- 初步打通 React 前端与推荐服务

目前最大的难题还是**怎么找到真正符合口味的书，以及怎么确认这些书真的存在**。

有些作品暂时找不到可靠的原站信息，推荐结果也还有不少需要改进的地方。

## 💻 技术实现

- **Frontend:** React, TypeScript
- **Backend:** Python, FastAPI
- **Agent Workflow:** LangGraph
- **LLM:** Google Gemini
- **Search:** Tavily
- **Text Normalization:** OpenCC
